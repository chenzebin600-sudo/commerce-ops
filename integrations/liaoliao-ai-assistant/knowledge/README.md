# 客服政策知识库

- `global.md`：所有店铺共用的客服政策。
- `platforms/<平台名小写>.md`：平台规则，例如 `shopee.md`。
- `regions/<国家或地区小写>.md`：国家/地区政策，例如 `ph.md`。
- `shops.json`：按乐聊中显示的店铺名称配置专属政策。
- `products/<sku小写>.md`：商品/SKU 已确认资料。
- `intents/<场景>.md`：物流、退款、缺货等场景规则。
- `examples.jsonl`：经过人工采用的优质回复示例；每行一个 JSON 对象。

冲突优先级为：场景规则 > 店铺政策 > 商品资料 > 国家/地区政策 > 平台政策 > 全局规则。
系统还会从本地 SQLite 中检索人工采用过的相同店铺、相同场景回复作为示例。

仅填写已经确认且允许提供给模型的事实；不要填写密码、Token 或完整支付信息。
