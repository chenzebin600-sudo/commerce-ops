# 马帮多店铺刊登工作台

本地网页通过 `127.0.0.1` 上的 Python 桥接服务连接马帮刊登模块。账号密码只保存在当前进程内存，不写入网页、配置文件或浏览器存储。

## 启动

双击：

```text
启动本地刊登看板.cmd
```

启动器会构建网页、启动本地马帮桥接服务并打开：

```text
http://127.0.0.1:3000
```

页面默认显示操作账号“陈泽彬”。如果实际马帮登录名不同，可在连接表单中修改；密码每次启动后重新输入。

## 当前能力

- 动态读取 Lazada、Shopee、TikTokShop 的授权店铺和刊登列表。
- 按平台状态、店铺、标题、SKU 或平台商品 ID 查询。
- Lazada 在线商品批量修改：
  - 售价
  - 促销价
  - 库存
  - 包裹长度、宽度、高度
  - 包裹重量
- 支持 DeepSeek AI 结构化解析，例如：`SKU A 泰国 Lazada 售价上涨10%`。
- 同一登录会话内可切换到“新建商品刊登”，支持：
  - 手动创建 Lazada 商品资料
  - 将在线商品复制为本地刊登草稿
  - 使用 DeepSeek 生成可编辑商品资料
  - SQLite 持久化草稿、版本、变体、图片、发布任务与事件
  - 马帮草稿回读校验、人工确认、立即刊登与批次状态跟踪
- DeepSeek 不可用时，简单的价格、库存和包裹字段指令仍可使用原有规则解析。
- AI 只输出经过本地 Schema 校验的 JSON，Phase 1 不允许 AI 直接执行商品修改。
- 先读取最新详情并展示逐字段差异，再由用户点击确认同步。
- 执行时逐商品串行提交，提交前检查原值，提交后重新读取详情验证。
- 每个商品的结果写入本机 `work/audit.jsonl`，其中不含马帮密码或令牌。

## Phase 1：配置 AI 解析

DeepSeek API Key 只从本机环境变量读取，不写入代码、网页或审计日志。

首次配置可在 PowerShell 中执行：

```powershell
setx DEEPSEEK_API_KEY "你的 DeepSeek API Key"
```

设置后需要关闭并重新打开本地刊登看板。可选环境变量：

```text
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
```

AI 解析接口为 `POST /api/ai/parse`。它只返回结构化指令和意图预览，
不会调用马帮保存接口。

## 尚未开放

- 在线 SKU A → SKU B：马帮标准在线编辑页禁用了 SKU 输入，不能使用普通在线保存接口冒险修改。
- 规格名称/枚举替换：需要继续捕获马帮专用批量编辑或重新刊登接口。
- Shopee 与 TikTokShop 写入：当前仅开放动态查询，待分别捕获并验证写入负载。
- Lazada `task/save` 完整请求体、草稿回读接口，以及发布完成后的平台商品 ID/链接解析接口仍需在马帮页面继续捕获。系统会明确提示该阻塞点，不会伪造成功。
- 已固化 `task/publish` 与马帮批次状态查询；在 `task/save` 和回读接口捕获完成前，正式发布按钮不会绕过校验门槛。

## 安全边界

- 桥接服务只绑定 `127.0.0.1:8877`，不会暴露到局域网或公网。
- 浏览器写请求必须携带本次运行生成的本地令牌。
- 每次预览 15 分钟后过期，且同一预览只能创建一个执行任务。
- 单次最多 100 个商品，同时只允许一个批量同步任务。
- 价格与库存等字段有类型和范围检查；促销价不得高于售价。
- 如果执行前发现马帮原值已经变化，该商品会停止写入，避免覆盖他人的修改。
