# 数据仓库动态文档

这是一个仅在本机回环地址运行的数据仓库查询工具。它通过公司内网连接数仓服务，无需安装项目依赖。

## 启动前准备

- 使用 Windows，并安装 **Node.js 20 或更高版本**。可在命令提示符中运行 `node --version` 查看版本。
- 电脑必须能访问公司内网；在外部网络使用时，请先按公司要求连接 VPN。
- 内部管理员需要预先配置 `DATA_WAREHOUSE_UPSTREAM_BASE_URL`，使本地工具能够找到公司内网中的数仓服务。若启动窗口立即提示异常退出，请先确认这项配置。
- 准备数据查询 Key。数据查询 Key 以 `zndr_` 开头；以 `zntk_` 开头的是其他用途的令牌，不能用于本工具。

请勿把完整 Key 写入本文档、聊天消息、截图或故障日志。

## 启动和停止

1. 双击 `启动数据仓库文档.bat`。
2. 保留弹出的批处理窗口。工具会自动打开浏览器，并在窗口中显示实际访问地址。
3. 使用完成后，**关闭批处理窗口即可停止工具**。关闭浏览器标签页不会停止后台进程。

工具只监听本机 `127.0.0.1`，按顺序尝试端口 **4788–4797**。如果 4788 已被占用，会自动选择下一个可用端口；请以启动窗口打印的地址为准。不要把工具暴露到局域网或公网。

## 查询步骤

1. 在“连接数据仓库”区域输入以 `zndr_` 开头的 Key，然后选择“连接”。Key 输入框默认隐藏内容。
2. 连接成功后，确认页面显示的数据范围，并选择“日销”“库存”“产品包”或“控价”。实际可用产品由账号权限决定。
3. 填写页面显示的查询条件和每页行数，然后选择“查询数据”。每页行数必须为 1–2000；日销查询的开始、结束日期均为必填，且日期范围最多 92 天（含首尾日期）。
4. 查看结果表格。字段较多时，可在表格区域内横向滚动。
5. 页面出现“加载更多”时，选择它可按游标读取下一页；新数据会追加到当前结果中。
6. 有结果后选择“导出 CSV”。导出的文件使用 UTF-8 编码，可用 Excel 等表格工具打开。

切换数据产品会清空当前查询结果和分页位置。如需保留结果，请先导出 CSV。

## Key 的处理方式

Key 只保存在当前页面的内存中，用于向本机代理发起请求：

- 连接提交后，页面会立即清空输入框并恢复隐藏状态。
- 工具不会把 Key 写入浏览器的永久存储、会话存储、Cookie、URL、查询结果或 CSV。
- 关闭页面并停止批处理窗口后，本次会话中的 Key 即不再保留。
- 如需再次连接，请重新输入 Key。

## 常见问题

| 现象或状态码 | 含义和处理方式 |
| --- | --- |
| 启动窗口提示未检测到 Node.js | 安装 Node.js 20 或更高版本，重新打开批处理文件。 |
| 启动窗口提示 Node.js 版本过低 | 升级到 Node.js 20 或更高版本。 |
| 浏览器未自动打开 | 查看批处理窗口中的 `http://127.0.0.1:端口/` 地址，复制到浏览器打开。 |
| 无法连接本地工具或公司内网服务 | 确认批处理窗口仍在运行、电脑已连接公司内网或 VPN，然后重试。 |
| 400 | Key 格式或查询参数不正确；检查必填项、日期范围、页大小和可选值。 |
| 403 | Key 无效、权限已停用、产品未开通，或查询超出授权范围；确认使用的是数据查询 Key，并联系权限管理员。 |
| 429 | 数仓查询队列已满；稍后重试，避免连续重复提交。 |
| 502 | 本地中转服务无法完成数仓请求；检查公司内网连接，稍后重试，持续出现时联系内部技术支持。 |
| 端口 4788 无法访问 | 查看启动窗口；工具可能已选择 4789–4797 中的其他端口。 |
| 工具异常退出 | 保留窗口中的提示信息，但不要截取或发送完整 Key；确认内部服务地址配置和网络后重试。 |

如果 4788–4797 全部被占用，工具会退出。关闭占用端口的其他本地程序后，再次双击启动文件。
