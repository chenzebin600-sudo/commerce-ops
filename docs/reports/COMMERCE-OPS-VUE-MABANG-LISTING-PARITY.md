## 3. DeepSeek 配置

前端只读取非敏感状态，不接收或保存 API Key。实际调用继续由本机马帮刊登服务完成：

- `DEEPSEEK_API_KEY`：服务端密钥。
- `DEEPSEEK_BASE_URL`：默认 `https://api.deepseek.com`。
- `DEEPSEEK_MODEL`：默认 `deepseek-v4-flash`，也支持 `deepseek-v4-pro`。
- 历史值 `deepseek-v4` 由后端兼容映射到 `deepseek-v4-flash`。

页面会显示当前模型和配置状态。AI 只负责解析自然语言、确定作用范围并生成候选差异；实际写入仍要求用户在差异表中勾选并确认。

## 4. 平台字段语义

### Shopee

- `price`：原价。
- `sale_price` / `special_price`：售价。
- “价格修改”默认修改售价。

### Lazada

- `price`：售价。
- `sale_price` / `special_price`：促销价。
- “价格修改”默认修改促销价。

预览返回的原值会同步到当前列表变体，避免列表显示值与提交前校验值不一致。

## 5. 图片与库存安全边界

- 平台图片不直接作为浏览器 `src`，统一通过 `/api/image?url=` 本机代理读取。
- 图片进入可视区域前不下载，减少长列表请求量。
- 多仓库存按变体展示全部仓库名称与库存。
- 库存修改先调用仓库选项接口；存在多个仓库时必须使用后端推荐值或人工选择。
- 提交前重新读取马帮详情并生成差异，不使用页面陈旧值直接覆盖。
- 提交后同时展示马帮任务状态和平台详情回读结果。
