# Commerce Ops Vue 迁移设计

## 目标

- 使用 Vue 3、TypeScript、Element Plus、Pinia、Vue Router 和 ECharts 统一在线前端。
- 保留现有 URL、认证令牌、Node/Python API、Excel 导出和审计契约。
- Vue 构建输出到 `public/vue-preview`，正式根入口加载 Vue，旧版保留在 `/legacy/`。

## 信息架构

1. 运营总览：销售、货盘、店铺、履约与异常。
2. 商品与货盘：产品中心、销售与货盘驾驶舱。
3. 竞品与增长：链接、关键词、增长雷达与广告分析。
4. 店铺执行：马帮数据、商品刊登与履约中心。
5. 系统治理：导出中心、任务状态与操作记录。

## 迁移顺序

1. Vue 主壳、设计令牌、路由、全局筛选和真实数据总览。
2. 销售与货盘、增长雷达、履约中心。
3. 产品中心、马帮数据、商品刊登。
4. 竞品分析、广告分析、审计与最终入口切换。

## 当前完成状态

- 已完成全部主导航路由的 Vue 页面：运营总览、销售与货盘、产品中心、链接竞品、关键词竞品、增长雷达、广告分析、马帮数据、商品刊登、履约中心和操作记录。
- 产品中心已接入目录、筛选、详情、编辑、软删除和恢复；马帮模块已接入即时采集、调度任务、执行记录和图片任务。
- 广告分析继续调用隔离侧车服务，Vue 页面负责服务连接、统一认证、文件治理和入口呈现。
- Vue 已复用原有访问密钥和浏览器会话规则；旧版通过 `/legacy/` 提供显式回退路径。

## 质量门禁

- 所有页面支持 375、768、1024 和 1440 像素视口。
- 正文对比度不低于 4.5:1，交互目标不小于 44 像素。
- 路由级懒加载，图表按需注册，数据表默认使用服务端分页。
- 导出由后端生成正式文件并进入操作审计，不在浏览器中处理大数据工作簿。
