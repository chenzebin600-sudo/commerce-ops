## 3. 唯一粒度与关联

库存事实唯一粒度为：

```text
snapshot_at
+ source_sku
+ source_warehouse
```

迁移 `014_deterministic_growth_radar_scope_and_linkage.sql` 增加该粒度的唯一索引。禁止仅按 SKU 合并库存，也禁止把同一 SKU 的不同仓库记录直接相加后覆盖仓库事实。

订单商品行保存来源仓库和标准化来源仓库。订单与库存的关联键为：

```text
source_sku + source_warehouse
```

真实隔离验证结果：

| 指标 | 结果 |
|---|---:|
| 订单商品明细 | 2,659 |
| 匹配库存快照 | 2,658 |
| 未匹配 | 1 |

唯一未匹配行为 SKU `P4GG1790785`、仓库“菲律宾半溪-K仓-1308”、订单状态“已作废”；原因码为 `inventory_key_not_visible_in_source_scope`。作废状态不阻止关联验证，但该行本身不进入自有有效销量。

店铺国家映射不再阻塞订单库存关联。店铺映射继续服务于店铺覆盖、国家、平台、产品身份和后续推荐。

## 4. 销售指标分层

`growth_sku_warehouse_sales_metrics` 与库存快照保持相同的 `snapshot + SKU + 仓库` 粒度，并明确保存两层来源：

| 层 | 标准字段 | 来源与状态 |
|---|---|---|
| 自有真实销量 | `own_sales_quantity_7d` | 订单商品明细；按付款日 7 日窗；排除 `invalid_cancelled` |
| 自有订单数 | `own_sales_order_count_7d` | 同一窗口的非作废订单去重数 |
| 自有有效明细数 | `own_sales_effective_line_count_7d` | 同一窗口的非作废商品行数 |
| 库存范围销量 | `source_visible_sales_7d` | 库存导出 `销量(7/28/42)` 第一段 |
| 库存范围销量 | `source_visible_sales_28d` | 库存导出 `销量(7/28/42)` 第二段 |
| 库存范围销量 | `source_visible_sales_42d` | 库存导出 `销量(7/28/42)` 第三段 |
| 来源预测 | `source_predicted_daily_sales` | 库存导出 `预测日销量(个)` |

真实 7 日订单窗口完整覆盖 2026-07-15 至 2026-07-21，因此 1,438 个指标行的 `own_sales_quantity_7d_status` 均为 `confirmed`，按 SKU + 仓库汇总的自有有效销量为 2,434 件。

预测日销量状态固定为：

```text
source_predicted_daily_sales_status = source_prediction_not_actual
```

该字段不是逐日真实销量，不与自有订单销量相加。库存账号权限范围仍未确认，所以三个来源可见销量字段也不得改名为公司销量。

## 5. PII 白名单

订单摄取改为显式字段白名单。允许进入订单原始行 JSON 的 17 个字段为：

```text
订单编号、交运时间、店铺名、平台、订单状态、仓库、SKU总数量、SKU、商品数量、
商品中文名称、商品销售单价、订单核算金额（人民币）、付款时间、平台SKU、
订单商品名称、SKU明细、作废时间
```

真实文件中识别并过滤 8 个 PII 表头：

```text
所属地区（省/州）、所属城市、客户账号、客户姓名、
邮寄地址1(按逗号分隔导出2列)、电话1、电话2、邮政编码
```

其余非白名单字段也不进入 `raw_values_json`。隔离库逐行检查结果：含 PII 的原始 JSON 键为 0；客户账号、姓名、地址、电话、邮编和收件信息写入量为 0。批次只保存文件基名、SHA-256 和可控来源引用，不保存本机绝对路径。

## 9. G1B 进入判断

结论：**G1B 可以开始，但仅限确定性数据准备与映射收口；G2 评分仍禁止开始。**

依据：

1. 真实订单与库存结构、类型和值域已经完成审计。
2. `SKU + 仓库` 能覆盖 2,658/2,659 个订单商品行，唯一异常是已作废且库存范围不可见的行。
3. 多仓粒度已由唯一索引和 278 个真实多仓 SKU 验证。
4. 自有销量、来源可见销量和预测值已分层，禁止相加和公司级命名。
5. PII 白名单、隔离库、幂等和质量问题机制已通过测试。
6. 店铺国家映射仍需人工确认，但不再是订单库存基础关联的前置条件。

G1B 的约束：来源权限范围继续为 `unconfirmed`；可用库存不自动等同于最终可售库存；店铺映射仍需人工确认；不得创建公司销量、AI 差额、机会评分、优先级或推荐结果。

## 10. 停止点

G1A.5 完成后暂停。当前提交只交付数据口径、迁移、解析、关联、销量分层、隐私控制、管理界面状态和验证工具，不实现 G2 评分。
