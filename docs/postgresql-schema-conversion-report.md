## Type conversion rules

| SQLite shape | PostgreSQL type | Rule | Risk |
|---|---|---|---|
| `INTEGER PRIMARY KEY AUTOINCREMENT` | `bigint GENERATED BY DEFAULT AS IDENTITY` | Preserve explicit IDs and reset identity sequence | PostgreSQL creates a physical PK index where SQLite rowid did not |
| Boolean-like `INTEGER` | `boolean` | Only 0/1 accepted and converted to false/true | Future non-0/1 values must fail migration |
| Other `INTEGER` | `integer` or `bigint` | File-size fields use bigint | JavaScript bigint values remain decimal strings |
| JSON `TEXT` | `jsonb` | Parse and validate every non-null value | Malformed JSON must block migration |
| `*_at`, `lease_until` TEXT | `timestamptz` | Normalize SQLite UTC strings to ISO-8601 UTC | Zone-less timestamps are interpreted as UTC |
| `*_date` TEXT | `date` | Require YYYY-MM-DD | Time components are intentionally excluded |
| UUID-like `id`/`*_id` TEXT | `uuid` | Validate RFC-compatible UUID text | Future platform IDs must not be guessed as UUIDs |
| Other `TEXT` | `text` | Preserve value | Collation differs from SQLite |
| `BLOB` | `bytea` | Byte-preserving conversion | No current production columns use BLOB |
