# Shopee 折扣控价：数仓中转 API 适配设计

## 目标

让 Shopee 折扣控价模块使用公司局域网数仓中转服务读取“控价”产品，并继续保持预览优先、人工确认、默认不写 Shopee 的安全边界。

## 已确认的外部契约

- 固定基址：`http://10.110.80.95:8788`
- Key 验证：`GET /api/data/me`
- 控价查询：`POST /api/data/query`
- 认证头：`X-Data-Key: zndr_...`
- 查询产品：`控价`
- 查询参数：`平台=SHOPEE`，并按 `国家`、`大品类`、`SKU` 收窄
- 分页：请求使用 `页大小`、`游标`；响应使用 `游标`、`还有更多`
- 批次水位：只使用响应的 `源最新`，不得用 `本页最新`

## 适配方案

`WarehouseControlPriceClient` 保持为 Shopee Discount 领域层唯一数仓入口，但内部协议改成上述真实中转契约。验证与查询共享同一个受保护的 Key 解析器；Key 只进入 `X-Data-Key` 请求头，不写日志、错误、审计证据或前端响应。

客户端只允许两类基址：HTTPS，或精确匹配 `http://10.110.80.95:8788` 的局域网例外。任何其他明文 HTTP 地址继续在构造阶段拒绝。该例外是当前基础设施限制，不代表一般性降低传输安全要求。

查询采用服务端允许的最大安全页大小以内分页，并串行翻页，符合“每人同时一个请求”的限流约束。游标缺失、重复、页数超限、返回总量或水位不一致均失败关闭，不把不完整结果当成 SKU 缺价。

## 字段与范围

响应继续通过现有中文字段别名归一化为领域字段：SKU、国家、大品类、平台、状态、日常价、活动价、大促价和各档批准时间。响应顶层的 `源最新` 注入每条归一化记录作为同一批次水位。平台固定为 `SHOPEE`。国家、大品类和 SKU 必须与本次请求范围一致；越界行、重复国家-SKU-平台行或未知字段形态均阻断预览。

中转文档只承诺单个 `SKU` 参数，不假设支持逗号列表。预览请求包含多个 SKU 时，适配器按国家和大品类读取完整的有权控价分页，在一次预览 `requestId` 内缓存该只读快照，再对每个调用方 SKU 集合做精确本地筛选；单 SKU 的执行前复核使用服务端 `SKU` 参数收窄。缓存必须同时绑定国家、大品类和 `源最新`，只在当前预览生命周期使用，不能跨预览复用。

## 错误处理

- 未配置基址：`SHOPEE_DISCOUNT_WAREHOUSE_ENDPOINT_UNCONFIGURED`
- Key 无效或未授权：稳定映射为数仓 Key 验证失败，不暴露响应原文或 Key
- 429：按中转说明做有限退避，写接口仍为零重试
- 502、超时、网络中断、非 JSON：`WAREHOUSE_UNAVAILABLE`
- 不完整分页或水位变化：继续使用现有分页/水位阻断码

页面只显示可操作的中文错误。用户必须在页面自行填写 `zndr_...` Key，保存后再验证；Key 不通过聊天传递。

## 配置与上线

本机 `.env` 配置 `SHOPEE_DISCOUNT_WAREHOUSE_BASE_URL=http://10.110.80.95:8788`。重启 3101 后，未填写 Key 时仍失败关闭；填写并保存 Key 后，验证按钮只调用 `/api/data/me`。验证通过后才允许生成数仓价格预览。

## 验证标准

1. 合约测试证明 URL、HTTP 方法、中文 JSON 请求体、`X-Data-Key` 和游标完全匹配文档。
2. 测试证明仅精确内网基址可以使用 HTTP，其他 HTTP 被拒绝。
3. 测试证明 `源最新` 是唯一批次水位，跨页变化会阻断。
4. 测试证明 Key 不出现在错误、返回值和日志型证据中。
5. 使用用户在页面保存的真实 Key 做一次 `/api/data/me` 验证和一条小范围控价只读查询；不得触发 Shopee 写入。

## 非目标

- 不改数仓服务端。
- 不签发、展示或代用户输入数据 Key。
- 不开放任意 HTTP 主机。
- 不改变人工审批、执行安全闸门或 Shopee 写入策略。
