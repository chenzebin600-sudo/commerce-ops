# Shopee 空预览不占活动窗口设计

## 目标

当价格预览没有发现任何虾皮变体时，不得留下 `PREVIEWED` 活动计划，也不得占用店铺的目标时间窗口。

## 行为

- `CURRENT_CORRECTION` 未发现变体：返回 `SHOPEE_DISCOUNT_NO_ACTIVE_VARIANTS`，提示现有活动中没有可处理变体，并建议新店切换到“新建或续期折扣活动”。
- `NEXT_RENEWAL` 未发现变体：返回同一错误码，提示所选店铺没有虾皮在售变体。
- SQLite 兼容预览在创建领域计划前拒绝空结果，因此不会写入活动窗口。
- 生产流式预览因需预先建立可恢复草稿，在扫描结束发现空结果时，将草稿从 `PREVIEWING` 原子转换为 `CANCELLED`，然后返回业务错误。
- 已取消的空草稿不创建 Foundation 人工确认计划，不触发虾皮写入，也不阻塞同店后续预览。

## 验证

- 回归测试先证明旧行为会生成 0 项 `PREVIEWED` 计划。
- SQLite 路径断言空预览被拒绝且未创建计划。
- 生产路径断言空草稿为 `CANCELLED`，随后同店 `NEXT_RENEWAL` 可成功生成预览。
